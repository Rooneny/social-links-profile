# Social Links Profile

## Overview

This is my solution to the Social Links Profile challenge on Frontend Mentor.

I built this project using HTML and CSS to practice creating responsive layouts, improving accessibility, and writing cleaner code.

## Features

- Responsive profile card
- Social media links
- Hover and keyboard focus effects
- CSS custom properties for colors
- Flexbox layout
- Inter font from Google Fonts

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Variables
- Google Fonts (Inter)
- Responsive Design

## What I Learned

During this project, I practiced:

- Using Flexbox to center elements.
- Organizing colors with CSS variables.
- Using relative units and flexible widths.
- Creating hover and focus-visible effects.
- Improving spacing and typography.
- Structuring HTML with semantic elements.

## Challenges

One of the main challenges was managing the spacing between the profile information and social links.

I also worked on making the card responsive while keeping the layout consistent across different screen sizes.

## Future Improvements

- Improve CSS organization.
- Make the layout more flexible.
- Continue improving accessibility.
- Write cleaner and more maintainable code.
